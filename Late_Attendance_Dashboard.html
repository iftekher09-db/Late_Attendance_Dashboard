Late Attendance Analytics

Connect with your GitHub token. The dashboard opens with all previously saved monthly data, and new months you upload are preserved in GitHub.

The dashboard starts blank. Add data month by month with the ⬆ Upload Monthly Data button in the header — select the Year & Month, pick the Analysis file, and it is saved to GitHub. On every open, the dashboard shows all previously saved months until you add the next one.
Use a fine-grained token scoped to this one repository with Contents: Read & Write. If "Remember on this device" is ticked, the token is kept in this browser's local storage (never committed to the repo) — untick it on shared computers. Create one at github.com/settings/tokens.
